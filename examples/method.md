# 示例方法

请制作两页可编辑流程图，使用 Arial 和英文节点。

第一页：读取数据表与样本清单，校验文件、样本 ID 和单位，并保存真实 QC 报告。依据数据证据处理缺失字段，统一单位，得到校验后的数据。同一份数据分别用于数值特征和类别特征提取，两类结果共同形成特征矩阵。异常记录仅进入 QC，不进入特征矩阵。

第二页：从校验后的数据开始，依次排除重复记录、无效记录和不合格样本。任一排除条件满足就移除完整记录，并保留排除原因。剩余同一份记录独立进入方法 A 和方法 B，两条路线分别生成结果；两条路线各自保留未知与冲突结果作为 QC，不合并两路线的结果计数。

这是一份通用版式示例，不涉及实际样本、项目进度或已经执行的分析。
